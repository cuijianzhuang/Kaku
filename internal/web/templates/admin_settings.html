登录方式

在登录页显示「使用 GitHub / Google 登录」。配置后，每个管理员先用密码登录，在「安全」页面绑定自己的账号，之后才能用该账号登录；不会自动创建管理员，开启了两步验证的仍需输入验证码。

GitHub

在 GitHub → Settings → Developer settings → OAuth Apps 新建应用，回调地址填 {{.OAuthBase}}github/callback

Google

在 Google Cloud Console → API 和服务 → 凭据 新建「OAuth 客户端 ID（Web 应用）」，已获授权的重定向 URI 填 {{.OAuthBase}}google/callback

后台入口

开启后任何访客都能看到后台路径（安装时随机生成，用于防扫描）。开启时建议同时在「安全」页面开启两步验证。

Polaris 面板（套餐兑换码）

在 Kaku 出售面板里的用户套餐和流量包：买家付款后自动在面板生成兑换码发给买家，买家在面板商店或机器人里兑换；退款时作废未兑换的码。

保存后测试：检查地址、令牌和权限，并读取面板的套餐和流量包。

Polaris 授权服务

对接后，Polaris 商品付款即自动向 polaris-license 签发激活码，续费、退款吊销全自动。按下面三步完成：

① 填写授权服务地址和 API 密钥

② 在 polaris-license 的环境变量中加入以下配置并重启

密钥填上一步的同一个（生成后先复制保存）。只允许本服务器调用时，再加 KAKU_API_ALLOW_IPS=本服务器出口 IP。

KAKU_API_SECRET=（与上面相同的密钥）
KAKU_HOOK_URL={{.HookURL}}
KAKU_RENEW_URL={{.RenewURL}}{{if .RenewBot}}
KAKU_RENEW_BOT={{.RenewBot}}{{end}}

③ 测试连接

检查地址、密钥、IP 白名单和服务器时间，并读取授权服务的套餐、功能和许可证模板。
