支付

易支付（支付宝 / 微信）

异步通知地址 {{.Base}}/notify/epay。收到通知后验签、比对金额，并调用网关 api.php 二次查单确认。

USDT（TRC20）

每个订单金额带唯一尾数，链上确认后按金额自动匹配，约 20 秒检查一次。

Telegram Stars

仅在 Telegram 机器人中可用，需要先配置 Bot。

邮件（SMTP）

Telegram Bot

保存 Token 并填写 HTTPS 站点地址后点击；会自动读取机器人用户名并注册命令。

登录方式

在登录页显示「使用 GitHub / Google 登录」。配置后，每个管理员先用密码登录，在「安全」页面绑定自己的账号，之后才能用该账号登录；不会自动创建管理员，开启了两步验证的仍需输入验证码。

GitHub

在 GitHub → Settings → Developer settings → OAuth Apps 新建应用，回调地址填 {{.OAuthBase}}github/callback

Google

在 Google Cloud Console → API 和服务 → 凭据 新建「OAuth 客户端 ID（Web 应用）」，已获授权的重定向 URI 填 {{.OAuthBase}}google/callback
